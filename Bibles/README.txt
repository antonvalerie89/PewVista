Place Bible source files here.

Accepted import types in the app right now:
- PDF
- ZIP
- JAR
- JSON
- TXT
- USFM/SFM

PDF files can be stored now and converted later into the verse format the program will use.
ZIP Bible packs can also be stored here and extracted for later conversion.
JAR Bible packs from official mobile Bible downloads can also be stored here for later inspection or conversion.

Keep source and license notes in Bibles/licenses.
